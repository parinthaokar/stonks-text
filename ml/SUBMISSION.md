## 3–5 sentences

> **Stonks & Texts — Mood Engine** takes seven numbers describing a single trading day (the
> day's percentage move, volume relative to its 20-session average, up/down streak lengths,
> drawdown from the 52-week high, and two 52-week-extreme flags) and predicts which of eight
> "moods" the asset would text you in, returning the mood, calibrated probabilities across all
> eight, a real example message, and the three most similar days in the historical dataset.
> The scikit-learn Pipeline is **MarketMoodFeatures → StandardScaler → LogisticRegression**,
> where **`MarketMoodFeatures`** is my custom transformer (`BaseEstimator` + `TransformerMixin`)
> that expands the seven raw inputs into sixteen engineered features — magnitude, direction,
> log-scaled volume, capped streaks and a move×volume interaction — deliberately *without*
> encoding any of the rules engine's thresholds, so the model has to find the decision
> boundaries itself. The learned state lives in the scaler's per-feature means and standard
> deviations, the regression's coefficients, and a `NearestNeighbors` index over the 3,320-row
> scaled training matrix; all three are serialized into a bundle dict alongside the
> example-message corpus and build metadata. Built and served on **scikit-learn 1.9.1**
> (pinned into `requirements.txt` from the artifact's own metadata), it reaches 93.6% accuracy
> and 0.864 macro-F1 on a temporally held-out split against an 81.1% majority-class baseline.

**Custom transformer:** `MarketMoodFeatures` (in `ml/pipeline_def.py`)
**scikit-learn version:** `1.9.1`

## Checklist against the brief's "don't miss" list

| Failure mode | How it's avoided | Evidence |
|---|---|---|
| Custom class not in the Modal image | `modal_serve.py` ships `serve.py`, `pipeline_def.py`, `pipeline.joblib` with `copy=True`, and refuses to deploy if any is missing | `POST /predict` returns 200 on the deployed URL — impossible to unpickle without the class |
| sklearn version mismatch | `requirements.txt` generated by `build_pipeline.py` from the interpreter that fitted the artifact | `GET /pipeline` reports `1.9.1`, matching the build |
| Load-per-request | Module-level load at import in `serve.py`; a failed load is captured, not raised | 124 ms average response time across the Postman run |
| Frontend still on localhost | `NEXT_PUBLIC_MODAL_API_URL`, no localhost fallback in `src/lib/mood-api.ts` | deployed page contains the Modal URL and no `localhost` |
| Postman hitting localhost | `base_url` collection variable = Modal URL; an assertion explicitly fails if the host contains `localhost` | assertion "not hitting localhost" passes |

## Rebuilding from scratch

```bash
npm run ml:export                          # label 3,320 days from the rules engine
scripts/.venv/bin/python ml/build_pipeline.py   # fit + dump pipeline.joblib + requirements.txt
cd ml && modal deploy modal_serve.py
```
