## 3 sentences

> I chose **logistic regression** because the output is one of three discrete actions
> (sell / hold / buy) rather than a number, and it handles three classes natively via softmax —
> and because a random forest and gradient boosting scored within noise of it on held-out data,
> so the extra complexity bought nothing while logistic regression alone gives readable
> coefficients. The service takes ten strictly backward-looking numbers describing a single
> trading day — the day's move, volume against its 20-session average, realised volatility,
> distance from the 50-day average, drawdown from the 52-week high, two 52-week-extreme flags,
> up and down streak lengths, and a crypto flag — and returns a suggested action with a
> probability for each, using my custom transformer **`MarketContextFeatures`**, which expands
> those ten inputs into twenty-one engineered features with no hand-coded thresholds so any
> decision boundary had to be learned rather than supplied. Built and served on
> **scikit-learn 1.9.1**, it scores 34.5% on a temporal split with a 10-day embargo against a
> 36.9% majority baseline — it does not beat that baseline, which is the expected result for
> daily direction prediction, and the API returns that fact with every response.

## Checklist against the brief's "don't miss" list

| Failure mode | How it's avoided | Evidence |
|---|---|---|
| Custom class not in the Modal image | `modal_serve.py` ships `serve.py`, `pipeline_def.py` and `pipeline.joblib` with `copy=True`, and refuses to deploy if any is missing | `POST /recommend` returns 200 on the deployed URL — impossible to unpickle without the class |
| sklearn version mismatch | `requirements.txt` generated by `build_pipeline.py` from the interpreter that fitted the artifact | `GET /pipeline` reports `1.9.1`, matching the build |

| Postman hitting localhost | `base_url` collection variable = Modal URL, plus an assertion that fails if the host contains `localhost` | assertion "NOT hitting localhost" passes |

## On the accuracy

The model does not beat a majority-class baseline, and this is not hidden. Three framings
were tested before settling here — direction, volatility magnitude, and nearest-neighbour
historical analogy — and none beat their baselines on a temporal split with an embargo. That
is the expected result: predicting daily direction for twelve of the most heavily traded
assets in the world from public price history is the most-attempted problem in quantitative
finance, and it does not work.

It is reported as a finding rather than a flaw. The project's existing backtest already
reached the same conclusion from a different direction, when a coin-flip control that traded
on the same days returned +1.9%. Arriving at it twice, by different routes, makes it stronger.
